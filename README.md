# Webnovel Income Calculator

[![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen.svg)](https://mhk456.github.io/income-caculator-WN/)

## Overview
The Webnovel Income Calculator is a tool designed to help writers estimate their potential income on Webnovel. It takes into account various factors such as average word count, total subscriptions, privilege coins, gifts received, and potential MGS (Minimum Guarantee System) or Win-Win bonuses to provide a detailed breakdown of estimated earnings. 

You can try out the live calculator here: [Webnovel Income Calculator](https://mhk456.github.io/income-caculator-WN/)

## About This Project
This is a personal side project I built for myself to better understand and project potential earnings. It uses standard estimates and my own formulas based on original inputs, combined with a modern UI, to visualize the income breakdown. 

**Note:** The results are estimates and actual final numbers might vary by 5% to 20% depending on various platform factors (e.g., free coin subscriptions or regional pricing differences).
